a few details

mandelbrot starts z at zero and varies c in z² + c. julia fixes c and varies the starting z. burning ship takes absolute values before squaring. tricorn uses the complex conjugate of z before squaring. cubic multibrot uses z³ + c.

newton basins use z ← z − (z³ − 1) / (3z²). instead of watching points escape, we're watching them find one of three roots. the boundaries are where the disagreements live.

dark means a point hasn't escaped, or hasn't converged for newton, within the iteration limit. it isn't a proof of anything. turn the iterations up if a fine edge looks unfinished.

ordinary views run on the gpu. deep zooms use a double-precision worker, which also takes over if webgl isn't available. dragging gets a quick preview, then a more detailed pass when you stop. the zoom limit is a width of 10⁻¹¹; beyond that ordinary floating-point numbers aren't much use here.
